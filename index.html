// Attack Surfaces & Exploitation Mapping
Advanced Cloud-Native Vulnerabilities & Remediations

Technical deep dives into multi-cloud container vulnerabilities, covering metadata exploitation paths, excessive privilege chaining, and cluster takeover vectors.

Critical Vector · AWS/Multi-Cloud
IMDSv1 SSRF Token Extraction
Attackers exploit Server-Side Request Forgery (SSRF) vulnerabilities inside a web container to query the legacy Instance Metadata Service (IMDSv1), stealing plain text node IAM role credentials.
Technical Mitigations
Enforce IMDSv2 tenant-wide, forcing a session-oriented token handshake via HTTP PUT.
Set token response hop limits to 1 to block transit through container network bridges.
Critical Vector · Azure Control Plane
Azure API Token Replay
Misconfigured cluster pods mounting cleartext Azure Managed Identity client secrets allow an attacker to dump access tokens straight from disk or environmental variables, enabling rogue ARM API elevation.
Technical Mitigations
Migrate all legacy Azure Pod Identities to modern Entra ID Workload Identities.
Enforce Azure Policy engines to block pods from picking up raw host identity metadata.
High Vector · GCP/Container Runtime
Shared Host Kernel Escape
A compromised container uses local privilege escalation vulnerabilities to trigger zero-day flaws inside the underlying host Linux kernel, escaping the container boundary to execute code on the parent node.
Technical Mitigations
Isolate untrusted internet-facing payloads using sandboxed gVisor runtimes.
Enforce Pod Security Standards to ensure container filesystems remain read-only.
